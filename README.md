# 读开窍 · 《开窍开悟开智》解读站

一套民间读本的结构化解读站：七个视图（首页 / 导读 / 章节脉络 / 概念关系 / 词典 / 人物谱 / 分段原文阅读器），
hash 路由、黑白双主题、Canvas 首屏动画、ECharts 脉络轴、内联 SVG 关系图、注疏高亮体系。

## 目录

```
index.html          页面骨架（无任何内联脚本）
.nojekyll           必须保留：避免 Jekyll 处理 assets
assets/site.css     样式
assets/data.js      window.KAIQIAO_TEXT（正文）+ window.KAIQIAO_SITE（解读数据）
assets/app.js       全部逻辑（经典脚本，ES2017 兼容）
assets/echarts.min.js  本地内置图表库，非 CDN
assets/favicon.svg  站点图标
```

## 本地预览

```bash
python3 -m http.server 8080
# http://localhost:8080/
```

也可直接双击仓库根目录的 `index.html`（脚本为相对路径经典脚本，file:// 下可用）。

## 数据与立场

正文按「书 → 部 → 章 → 段」结构化，段落是数组；章节字数、词频、共现关系、人物出现次数
均由正文逐字统计，无占位数据、无编造统计。第三、四部由影印件 OCR 识别，存在个别错字；
第一、二部原件未提供，未收录、未补写。
