开窍·开悟·开智

人性、认知与生存法则的民间读本

把三册原件拆成可以被检索、被对照、被追问的结构：先看清世界如何运转，再看清关系里的边界，最后看清钱与流量从哪里来。原文一字不改，观点保持原文立场，争议处另有辨析提示。

本机整理 · 仅供个人阅读学习 · 禁止商用与公开传播
01 / GUIDE

这本书在回答什么

按「读者会问的四个问题」重新编排九个部的材料。每个要点都锚定到真实章节，点开即读原文。

导读文字为编者概括，非原文；原文请以下方链接进入阅读器核对。书中含大量作者个人判断，本站只作整理，不作推荐。

02 / AXIS

章节脉络

这套书没有编年，因此时间坐标改为「章节坐标」：横轴是全部 170 章篇的先后顺序，纵轴是每章的真实字数，颜色深浅区分所属部。

可滚轮缩放、拖拽平移；点击任一点或明细行进入该章原文。窄屏自动切换为纵向章节流。所有坐标、字数均由正文统计得出。

当前为窄屏：散点图已转为下方纵向章节流，与宽屏数据一致，可直接点选。

03 / RELATIONS

概念关系

把词典里的概念摊开成一张图：节点大小对应它在正文中出现的次数，连线表示两个概念在同一章里共同出现，线越粗共现章数越多。

总览 → 悬停看明细 → 点击回词典。共现次数由正文逐字统计，非人工指定。四类概念按扇区排布，全站只用一种主色与一种反差色。

节点：概念（大小＝出现次数） 反差色：当前选中 连线：同章共现次数 点击节点 → 词条与出处
04 / GLOSSARY

概念词典

从正文中真实出现的高频术语里选出 38 个，按四类归置。释义为编者依据原文语境所作的描述性概括，并附一句原文与可回跳的章节。

出现次数、覆盖章数、原文引句、关联章节全部由程序统计，未作任何估算。带「辨析」标记的词条另附阅读提示。

05 / FIGURES

人物与角色谱

这套书没有阵营与家族，有的是「谁在叙述、谁被援引、谁在行动」。按典籍人物、当代商业人物、叙述者与类型角色分组，全部来自原文真实出现。

每位条目下的出现次数与章节数由正文统计，点击「看原文出处」回到首次出现的章节。类型角色是书中的行动位置，不是真实人物。

06 / READER

分段原文

书 → 部 → 章 → 段。左侧章节树可搜索折叠，右侧正文可调字号、记住阅读位置。注疏三体系全站一致：概念实线、人名虚线、地名点线，点击看释义。
